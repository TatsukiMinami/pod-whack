いま起きていること

  • Pod を倒すと、ここに流れます

どうして元に戻るの？

  1. タップすると、このアプリが Kubernetes の API に DELETE pod を送ります。
  2. Pod の数を見張っている ReplicaSet コントローラが、「6 個のはずが 5 個しかない」と気づいて、新しい Pod を作ります。
  3. スケジューラが置き場所のノードを決め（Pending）、ノードの kubelet がコンテナを起動します（ContainerCreating）。
  4. 起動を確かめたら Running。「あるべき姿」に戻るまでの時間が、上の「復活」です。

このアプリは自分の namespace の Pod を消す権限しか持っていません。ほかのアプリには触れないので、安心して倒してください。
